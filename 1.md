# Жизненный цикл (ЖЦ) разработки ПО (SDLC): этапы, виды моделей и их различия

**Жизненный цикл** — путь, который проходит продукт: от момента задумки до вывода из эксплуатации.

## Этапы ЖЦ ПО

### 1. Планирование и анализ требований

Включает в себя:

- описание задач, которые должен решать продукт;
- опрос стейкхолдеров;
- выявление аудитории, которая будет пользоваться решением;
- оценка ресурсов, которые нужны для реализации;
- согласование критериев.

### 2. Определение требований

- оценка рисков;
- выбор методов работы;
- описание пользовательских сценариев.

### 3. Проектирование

| Верхнеуровневое проектирование                                         | Низкоуровневое проектирование                                     |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Основные компоненты системы: модули, сервисы, подсистемы               | Принцип работы отдельных компонентов системы                      |
| Принцип взаимодействия этих компонентов между собой                    | Алгоритмы, структуры данных и логика работы внутри каждого модуля |
| Общая архитектура системы: клиент-сервер, архитектура или микросервисы | Детали реализации: какие классы, методы или функции будут созданы |
| Зависимость решения от других систем                                   | Взаимодействие с БД, API или другими внешними системами           |
| Протокол интерфейса                                                    |                                                                   |
